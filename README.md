# 🎬 Nolan Movie Ranker

A tiny, self-contained web tool for building your **Top 5 Christopher Nolan films**.
Drag films into ranked slots (1–5), or tap **+** to drop into the next open spot,
then copy or download your list. Top three slots get gold / silver / bronze medals.

No build step, no dependencies, no tracking — it's a single HTML file.

## Features

- 15 options: all 13 Nolan feature films (*Following*, 1998 → *The Odyssey*, 2026) plus two early shorts
- Drag-and-drop ranking with slot-to-slot swapping
- **Copy list** to clipboard and **Download .txt**
- **Save image** exports a polished, shareable PNG of your ranking
- **Surprise me** seeds a random Top 5 to tweak
- Editable list title
- Fully responsive, dark theme

## Use it

Just open `index.html` in any browser.

### Host it free on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** = *Deploy from a branch*, branch = `main`, folder = `/ (root)`.
4. Your ranker will be live at `https://<your-username>.github.io/nolan-movie-ranker/`.
